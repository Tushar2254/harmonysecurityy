# Home2 rollback snapshot

This folder contains the exact versions of existing files from before Home2 was connected.

To remove Home2 later:

1. Copy `App.jsx` back to `src/App.jsx`.
2. Copy `Navbar.jsx` back to `src/components/Navbar/Navbar.jsx`.
3. Remove the new `src/pages/Home2` and `public/Home2` folders if their assets are no longer needed.

The original `src/pages/Home/Home.jsx` and `src/pages/Home/Home.css` were not changed.
